**⚠️ ROOT-CAUSE MECHANISM — CORRECTED (07-15, triager, verified HEAD ad69c2e9f via code + disasm):** the SPIR-V reload is **NOT** `shouldDuplicateInstAtUseSite` force-duplicating `CastDescriptorHandleToResource` in generic IR (that was our earlier framing across turns — WRONG). Verified: after hoisting, the descriptor is a **SINGLE shared value in generic IR** (one `getElement`/`SPIRVLoadDescriptorFromHeap`, visible in `-dump-ir`). The triplication is introduced **LATER, during SPIR-V EMISSION** — `legalizeIRForSPIRV`/emit walk at **`slang-emit-spirv.cpp:11913`** (runs AFTER the `-dump-ir` snapshot, which is why IR shows 1 load but disasm shows 3). At emit the descriptor realizes as a shared `OpAccessChain` (index math, once) + an `OpLoad` dereference **RE-EMITTED per use**. Disasm: 2 OpAccessChain, 6 OpLoad (3 tex + 3 samp) for 3 samples. **The fix lever is in SPIR-V emit/legalize, NOT the generic IR dup pass (slang-ir-util.cpp:2638).** Any PR must target the emit path.

**(a) as framed to jkwak:** when a descriptor load's def DOMINATES all uses AND pointer/index are INVARIANT (the hoisted-local case), emit ONE OpLoad and reuse its result-id instead of re-loading per use. **CRUX ANSWERED (07-11, triager, DISASSEMBLED SPIR-V at HEAD 4d91d47b, replied issuecomment-4944015739, fresh CREATE):** the SPIR-V reload is **NOT a hard SPIR-V requirement — it's an ARTIFACT.**
- HLSL + hoisted local → `ResourceDescriptorHeap[i]` 1×, reused ✓
- SPIR-V + hoisted local → descriptor `OpLoad` **3×** from SAME `OpAccessChain` (%32/%43/%52 ← %24) ✗ = reporter's exact complaint
- SPIR-V + `pinDescriptor()` → `OpLoad` **1×** (%25) feeding all 3 `OpImageSampleExplicitLod` ✓ — **PROVES one load feeding N samples is valid SPIR-V; nothing in spec forces the reload.**
The hoisted load is treated as re-materializable (kin to `shouldDuplicateInstAtUseSite` force-dup, slang-ir-util.cpp:2638) → OpLoad re-emitted per use → user's explicit local store not honored. pin() defeats it by forcing a materialized SSA value the duplicator won't re-clone. **Fix is clearly on our side and safe.**
