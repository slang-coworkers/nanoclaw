NG surfaces policy-revision asks (e.g. "add source X", "reduce cadence Y") in its 3-day briefings. Its stated rule: ask once, mention "deferred" once next cycle, then **drop silently** if still unanswered. Silence = "leave as-is."

**Why:** mirrors NG's deep-reads "do not re-ask" rule. Re-asking weekly turns deferred items into nags. Main has already seen the proposal once.

**How to apply:** when NG flags an ask in a briefing, give an explicit approve/deny in that turn rather than letting silence default to "drop." If unsure, ask the user — don't kick the can. Don't paraphrase NG's policy back at it; it has the rule, parent doesn't need to restate.
