**shader-slang/slangpy#1055** (opened 2026-07-12 by tekintatar, external). Reported symptom: `[Differentiable]` fn that BOTH contains a loop AND returns a vector (`float3`) yields **silently WRONG** input gradients (wrong magnitude + sign flips, no error). Forward exact. Worst failure class (models train on garbage grads silently).

**FIXER VERDICT — CONFIRMED (2026-07-12T18:58Z, VERIFIED by GPU execution + source read).** Real, deterministic, silently-wrong-gradient bug in **the Slang compiler's reverse-mode autodiff transpose (shader-slang/slang) — NOT SlangPy**. SlangPy is a faithful conduit.

**ROOT CAUSE RE-SCOPED (ablation-isolated):** the reporter's "loop + vector return" is a *symptom*, not the trigger. Real trigger = `bwd_diff` transpose of a **`vector/scalar` divide (`float3 / float`)** where the vector numerator and scalar denominator are **both loop-carried differentiable accumulators sharing a loop weight**. Deterministic (bit-identical across runs → not an atomic race), rel err ~0.7–0.9.
- Minimal pair (standalone Slang, `bwd_diff` direct, no SlangPy/tensors/torch): `G` (float3 num / scalar den, shared w) → max|bwd−FD| **1.51e0 WRONG**; `H` (scalar num, identical math) → **2.5e-5 exact**.
- Ordering proof: `P` (float3 divide THEN collapse) WRONG; `Q` (collapse to scalar THEN scalar divide, same math) exact. → divide-operand type is the trigger, not return type. Reconciles reporter's scalar-return control (collapsed before divide, never hit the buggy transpose).

**VERIFIED facts:** (1) reproduces on pure-Tensor `.bwds()` — torch + C++ grad pass-through DEFINITIVELY EXCLUDED; (2) reproduces standalone pure Slang — SlangPy codegen/marshalling/atomic-scatter excluded; (3) trigger = vector/scalar divide of coupled loop-carried diff accumulators (exp/bilateral weight + center-alias NOT required; plain polynomial weight still fails); (4) FD-trustworthy (stable eps 1e-2..5e-4); (5) NOT a 0.41→0.42 regression — bit-identical WRONG on both, Slang 2026.5.2; (6) SlangPy backward codegen identical scalar-vs-vector (source-verified). **Hypotheses (NOT verified):** H1 transpose mishandles cotangent split for vector operand of vector/scalar divide (`d num += cot/den`, `d den += -dot(cot,num)/den²`) — needs slang autodiff maintainer vs transpose IR; H2 sibling of #12070 (same subsystem, distinct symptom), not proven identical.
