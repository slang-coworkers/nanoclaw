**shader-slang/slangpy#1052** — PyTorch autograd hook silently dropped after a no-grad call to the same `[Differentiable]` function. Reporter: tekintatar. Filed/triaged 2026-07-12.

**Root cause (CONFIRMED in source by slangpy-triager):** torch-tensor call-data cache signature is `[Dn,Sm]` (ndim + scalar_type only). `requires_grad` is read into the tensor-info struct but never written to the cache key. Autograd hook is gated at dispatch on the *cached* `is_torch_autograd()` flag, frozen at build time. So a no-grad-first call caches `torch_autograd=False`; later same-shape/dtype grad calls reuse it → hook bypassed → `grad_fn=None` → `loss.backward()` fails. Explains the full asymmetry (only no-grad→grad is broken).

**Classification:** bug / high / P1 / torch-integration / backend-agnostic / NOT upstream-Slang.
