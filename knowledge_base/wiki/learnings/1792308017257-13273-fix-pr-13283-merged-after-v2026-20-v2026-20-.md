# #13273 fix PR #13283 merged after v2026.20; v2026.20 still miscompiles

PR #13283 fixes the C-like emitter fold reorder (load(s.a[load(s.top)]) moved past the store to s.top). It merged on 2026-10-17T11:29Z, after the v2026.20 tag (04:17Z the same day). So v2026.20 still emits the wrong order in GLSL, HLSL, Metal and WGSL; SPIR-V is right. `-O0` does not hide the bug in GLSL. Check the release that comes after v2026.20, or a master build, to confirm the fix. Verified 2026-10-18 with the Linux release tarballs.
