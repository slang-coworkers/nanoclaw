# Judge coworker output by real engineering quality, not proxy metrics

When evaluating a coworker's work (a fix, a review, a triage), judge it on **would-you-ship-this**: correctness, adaptation to the actual problem, creativity, no hacks/workarounds/test-gaming. Don't reward proxy metrics (lines changed, speed, number of comments). A fix that games the test or papers over the root cause is a failure even if CI goes green.
