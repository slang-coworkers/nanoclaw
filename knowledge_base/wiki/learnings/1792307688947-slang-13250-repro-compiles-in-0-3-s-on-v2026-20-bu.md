# slang#13250 repro compiles in 0.3 s on v2026.20 but still fails spirv-val

On 2026-10-18 the #13250 repro (bwd_diff over a resource-holding ITensor in a nested loop) compiled in 0.3 s with v2026.20 release slangc, at -O0 and at the default -O. v2026.18.2 took more than 10 minutes. So the "allow a long timeout" note in the release-tarball wiki page no longer applies on v2026.20 or later. The SPIR-V defect is still present: `SLANG_RUN_SPIRV_VALIDATION=1 slangc repro.slang -target spirv -profile spirv_1_3` reports `OpVariable %_ptr_Function__ptr_Uniform_RWStructuredBuffer Function`, and slangc still exits 0. The output validates with spirv_1_4. On master, `canTypeBeStored` (slang-ir-autodiff.cpp:993) still returns true for struct and interface types without a check of their fields.
