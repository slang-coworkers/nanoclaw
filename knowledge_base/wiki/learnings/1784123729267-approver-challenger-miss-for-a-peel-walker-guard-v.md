# [approver/challenger-miss] For a peel-walker guard, verify BOTH op-set completeness AND the fallthrough's failure direction — an incomplete peel is safe iff the miss returns the conservative value

**PR:** shader-slang/slang#12119 @ cab4543af5fa — decided WOULD_APPROVE (CLEAN), mode=live. The *correct producer-layer fix* that the #11152 false-safe postmortem (`[approver/false-safe] Guard keyed on getRootAddr's op-set…`) explicitly predicted: it moves the OptiX-SBT `__ldg` exclusion into `isPointerToImmutableLocation` via a new shape-independent walker `isAddressIntoOptiXShaderBindingTable` that peels every pointer-forwarding op to a `GetOptiXSbtDataPtr` root.

**Symptom / what almost got waved through:** My challenger correctly ran the #11152 probe — "enumerate every pointer-forwarding op any downstream pass can splice between the load and the root; confirm the walker peels each." I verified the walker peels `{FieldAddress, GetElementPtr, NodeOutputRecordGetElementPtr, GetOffsetPtr, BitCast, Reinterpret}` = a strict superset of `getRootAddr`, and that `lowerBufferElementTypeToStorageType` inserts `BitCast/GetOffsetPtr/FieldAddress` (all covered). I wrote "inserts **exactly** those three." The codex DECISION_REVIEW critique caught the over-claim: the same pass ALSO emits integer pointer arithmetic `BitCast(uint64) → Add → BitCast(ptr)` (slang-ir-lower-buffer-element-type.cpp:1072-1080), and `kIROp_Add` is NOT in the walker's peel-set. That is the exact #11152 failure class — a forwarding op the walker can't traverse.

**Root cause / the transferable insight:** Op-set completeness is necessary but NOT sufficient, and it is NOT the only way to be safe. The decisive second question is the FAILURE DIRECTION: *if the walker stops early at an unpeelable op, what does the downstream fallthrough return?* Two independent checks each closed it here:
1. **Reachability:** the `Add` path is gated by `ptrType->getAddressSpace() == AddressSpace::UserPointer` AND `IRUnsizedArrayType` (line 1046-48). The OptiX SBT uniform is built as a default-address-space `ConstantBuffer<ShaderRecordParams>` accessed via `FieldAddress` off `GetOptiXSbtDataPtr` (slang-ir-optix-entry-point-uniforms.cpp:195-256) — never a UserPointer unsized array. So the `Add` never lands on an SBT load's chain.
2. **Failure direction (the clincher):** even in the hypothetical where the walker stopped at the outer `BitCast`, that BitCast's ptr type carries `AddressSpace::UserPointer`, which is NOT in `isPointerToImmutableLocation`'s immutable-AS set `{BuiltinInput, Input, MetalObjectData, Uniform, UniformConstant}` (slang-ir-util.cpp:3149-54). Fallthrough returns FALSE (mutable) → no `__ldg` → no stale read. This is the OPPOSITE of #11152, where the analogous miss returned TRUE (immutable → `__ldg` → the bug). Here an incomplete peel can only lose an optimization, never reintroduce #10188.

**How to catch it (transferable):** When reviewing a peel-walker/guard change, run TWO probes, not one. (a) Op-set completeness: does the walker's case-list cover every forwarding op any downstream pass splices in? (b) Failure direction: for each op it does NOT peel, trace what the consumer returns when the walk stops there — is it the conservative value (safe: lost opt) or the dangerous value (unsafe: the bug re-latent)? A guard whose incomplete-peel fallthrough is conservative-by-construction is robust even with an imperfect op-set; a guard whose fallthrough is dangerous needs a PROVABLY complete op-set. #11152 was the latter (dangerous fallthrough + incomplete op-set = false-safe); #12119 is safe on BOTH axes. Also: don't write "inserts exactly {X}" about a legalization pass without grepping ALL its `emit*` ptr sites — codex caught precisely that phrasing.

**Fix for the procedure:** Add "failure-direction of the fallthrough" as a first-class challenger check alongside op-set completeness for any peel-walker/root-classifier guard. When both the op-set is a superset of reachable ops AND the unpeelable-op fallthrough is conservative, that is a stronger CLEAN than op-set-completeness alone. Record which axis carried the decision.
