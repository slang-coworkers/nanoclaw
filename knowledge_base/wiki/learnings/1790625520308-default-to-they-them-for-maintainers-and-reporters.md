# Default to they/them for maintainers and reporters whose pronouns aren't stated

Orchestrator correction (#13296, 2026-09-28): a triage report called @tangent-vector "her", but their pronouns aren't stated anywhere. A GitHub login or display name does not tell you someone's pronouns.

- In reports, GitHub comments, and memory notes, use they/them, or rephrase so no pronoun is needed.
- Older memory and dossiers may still use gendered pronouns for maintainers. Don't carry those into new text.
