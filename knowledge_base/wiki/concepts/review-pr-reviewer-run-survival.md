# Reviewer-Run Survival & Review-Tool Operational Infra

Reviewer/Devin run survival, invocation, posting, and the critique gate. Related: [approver decision & shadow-mode](review-pr-approver-decision-and-shadow-mode.md), [harvest tiers](review-pr-harvest-tiers-and-verdict-reporting.md), [runner reliability](agent-infra-f0909b0-codex-and-pr-review-runners.md).

## TL;DR
- **Reviewers fail toward CLEAN** — a dead run can fake success (0/0/0, exit 0); check size/heading/guards/tool uses before trusting "no findings".
- **The outer turn must outlive its jobs** — turn end/interrupt/restart kills background runs (even `setsid`); use re-armed bounded polls; a verdict can ship with `reviewers_complete:false`.
- **Inner-lead orphaning fixed by default** (`CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1`); always pass `--max-budget-usd`; on a stub run the missing `.claude/agents/*` lenses yourself.
- **Budget cut (`error_max_budget_usd`), not just teardown**: $30 too little for ~700–900 lines — give 45–60, re-dispatch only missing lenses.
- **Recover a stub from `stream.jsonl`/`reviewerA.log` before re-running** (merge can drop a verified crash).
- **Isolate and identify:** private `REPO_ROOT` worktree, run dir from the echo (never newest-mtime); guard false-trips → adjudicate by sha and content.
- **Run scripts from `/home/node/.claude/skills/` via `bash`** (read-only `/app/skills` + missing exec bit fail yet look like success).
- **First Devin exit 3 = "not done yet."** Devin-only tier: retry once; B runs once ungated by `isDraft`; no outer `timeout`; never pre-fill `reviewers_complete:true`.
- **Gate counts only exact `/codex-critique` calls**; DECISION_REVIEW/OUTPUT_REVIEW separate; read PRs via `gh pr view --json`/`gh graphql`.
- **`post-review.sh` has no bot disclaimer** (append first, edit via GraphQL); **fast self-merge is normal** — no escalation on the first silent reping.
- **Post-last-round and test-only pushes get a direct diff verification (check each named nit) or a one-test rerun with the existing binary — not a re-dispatch**.
- **A session error mid-OUTPUT_REVIEW resumes, it doesn't re-run**: retry just the aborted step after re-verifying artifacts + head.

## Outer turn: keeping background jobs alive

Background runs die at teardown (`stopped`, run_dir gone, or a <500 B stub) ([#12023](../learnings/1783969636640-approver-reviewer-runs-are-session-teardown-fragil.md); [#12060](../learnings/1783964822172-approver-infra-abstain-pr-merged-undecided-while-r.md) merged undecided). Persist the run-dir path; the deliverable must be ≥500 B and cover the current head ([verify](../learnings/1783971373048-slang-pr-review-verify-reviewer-runs-survived-clea.md)); a terminal event with empty `review/` and no `tmp/decided` is a coverage miss. Escalating on the first silent reping was overruled — fast self-merges trip it ([ruling](../learnings/1783965620899-approver-clause-gap-operator-ruling-do-not-escalat.md)).

**Ending your own turn triggers teardown**: the host stops the idle container minutes later, killing `nohup` jobs: 7 h ([#13283](../learnings/1790619062342-slang-reviewer-ending-the-turn-after-dispatching-b.md)), 2× ([#13315](../learnings/1790686802018-container-stops-when-the-turn-ends-keep-long-revie.md)), ~90 s in ([#13328](../learnings/1790712733292-reviewer-background-jobs-die-at-turn-end-keep-the-.md)), an 11 h wait ([#13541](../learnings/1791764268124-never-end-a-reviewer-turn-on-a-background-wait-for.md)). So: launch with `setsid nohup … < /dev/null &`, stay in the turn, block in re-armed bounded polls (600000 ms timeout) until every job exits, merge in the same turn (removing the orphaned `wt-clarity-*` worktree), and send the verdict naming reviewers still running, or an ETA.

**User interrupts kill `setsid` jobs too** (#13333) ([interrupts](../learnings/1790727232799-user-turn-interrupts-kill-setsid-d-reviewer-jobs-k.md)). Write `review-<N>-my-verification.md` as you go so the verdict can ship with dead reviewers `_skipped: killed by session interrupt_`; then `git status` the verify worktree and rerun the restore build.

**Container restarts SIGKILL detached A/C runs too** (#14525: rc=125, no exit-status). Re-dispatch A/C into fresh run dirs; keep dead dirs ([detached](../learnings/1794901762492-detached-reviewer-runs-die-with-container-restarts.md)). Dispatch mechanics: `setsid nohup … &` inside a bash call hangs that call until its timeout, but the setsid'd process survives — let the call time out, then poll artifacts (#14539) ([setsid](../learnings/1794915713884-detached-setsid-job-survives-bash-tool-timeout-dev.md)). The printed `$!` dies with the tool kill; the real detached child is `$!+2` — find it via `ps -eo pid,args` ([gh auth false negative](../learnings/1794908670329-gh-auth-status-false-negative-under-onecli-proxy-p.md)).

## Reviewer A: the inner lead ends its turn

**History.** The inner `claude --print` lead backgrounded 5–7 subagents and ended its turn; print mode has no next turn, so a 600 s ceiling killed them, leaving a fragment as `final-review.md` (exit 1, false 0/0/0) — any diff size ([#12782](../learnings/1789468288728-reviewer-a-empty-final-review-md-on-large-diffs-60.md), [#13305](../learnings/1790649618844-slang-pr-review-reviewer-a-can-die-silently-set-cl.md), [#13322](../learnings/1790707975468-reviewer-a-patch-mode-inner-orchestrator-can-end-t.md), [#13283](../learnings/1790757776971-reviewer-a-inner-claude-print-kills-background-sub.md), [#12646](../learnings/1790837192079-slang-pr-review-runner-export-claude-code-print-bg.md)). The ceiling variable was never baked in ([#13429](../learnings/1791151479459-slang-pr-review-runner-scripts-may-lose-exec-bit-r.md)); on [#13431](../learnings/1791168330129-reviewer-a-inner-cli-can-end-its-turn-with-backgro.md) (2.1.289) the lead still ended its turn — `CLAUDE_CODE_DISABLE_BACKGROUND_TASKS=1` ran the subagents in the foreground, all `completed`.

**Now the default:** `repro.sh` and `run-clarity.sh` both export it. No wall-clock bound → always pass `--max-budget-usd`.

**Variants.**
- **Silent (exit 0).** A passing 1.5 KB file can be a subagent fragment with all six `killed`: grep `stream.jsonl` for `"status": "killed"` + a review heading ([#13377](../learnings/1790895880915-reviewer-a-exit-0-can-still-be-a-silent-kill-check.md)).
- **Late.** Runs losing all subagents 17–22 min in: salvage `task_notification`/`result` summaries, report `reviewers_complete=false`; on a small delta use your verification + the prior review ([#13356](../learnings/1790803785855-reviewer-a-inner-cli-can-be-interrupted-mid-run-17.md)).
- **Early.** A permission denial on a compound `gh pr diff … ; echo …` ends the inner CLI before any subagent.
- **Orphan.** #13284 failed 2× (`killed.system=7`) ([2.1.285](../learnings/1790765591537-reviewer-a-slang-pr-review-runner-breaks-on-claude.md)); #13345 orphaned 3/3 ([3/3](../learnings/1790792204414-reviewer-a-orphan-is-now-3-3-on-claude-cli-2-1-285.md)). Diagnose via `subagent_stats` + `claude_code_version` in `stream.jsonl`. Parent text saying reviewers "are running in the background" = nothing recoverable: `mv` the dir to `*-INCOMPLETE`, re-run at most once ([#13378](../learnings/1790901257688-reviewer-a-background-subagent-orphan-recurs-subag.md)). Version is not the trigger (#13432 recurred on a restored 2.1.289); stop after one early exit ([correction](../learnings/1791209006651-correction-reviewer-a-early-exit-is-not-caused-by-.md)).
- **Narration-only (guard passes).** #14502 r2 completed everything, then ended its turn after "Now producing the final review." — 679 B passed the <500 B floor; the floor also passes a PREAMBLE-only message, and the infra guard `grep -qiE 'API Error|socket|rate.?limit'` false-positives on "rate-limit failures" prose while a complete 11 KB review sits in the dir. Always `head`-check for a `**Verdict**` line before merging; a small-but-nonzero file is a review only if it starts with the review shape, else re-run once. `wait-run` rc=125 with `stream.jsonl` stopping mid-tool-event (no OOM) = infra kill — retry once ([narration-only truncation](../learnings/1794845153917-reviewer-a-narration-only-truncation-passes-the-50.md); [detached runs die with restarts](../learnings/1794901762492-detached-reviewer-runs-die-with-container-restarts.md)).

**Substitute instead.** Run the missing `.claude/agents/*` lenses as Agent calls on the head worktree with the diff and REVIEW.md, label "Reviewer A (substitute)", `reviewers_complete=false`; a delta re-review needs one code-quality lens (~$3).

## Reviewer A: budget cutoffs on large PRs

**Success can be empty.** On #13363 R2 (~900 lines) all 7 subagents had 0 tool uses yet `summarize.py` said success: check per-row tool uses and an "incomplete" header ([#13363](../learnings/1791081955973-reviewer-a-on-large-slang-prs-the-30-budget-can-cu.md)).

**$30 does not cover a large diff; with no wait ceiling the cut moves to the budget.** #13363 and #13541 ended 3/7 short; #13425 lost two to the ceiling then two to the cap; #13564 (heavy IR) stopped 6/7 at ~$25 — `final-review.md` says "Review incomplete"; finished lenses survive in `task_notification` results. Give large/heavy-IR PRs 45–60 ([#13425](../learnings/1791132067717-reviewer-a-slang-pr-review-runner-runs-out-of-budg.md), [#13564](../learnings/1792060963846-slang-pr-review-reviewer-a-30-budget-can-stop-6-7-.md)); the [fleet budget table](review-pr-workflow-and-issue-hygiene.md) goes to 120–150 above ~15 files/~2k lines. Close the gap with the missing lenses only; keep `reviewers_complete=false`.

## Reviewer A: recovering a stub from stream.jsonl

Under ~1.5 KB is a stub; `<run_dir>/stream.jsonl` is the source of truth (subagent transcripts are deleted; `.meta.json` maps id→agentType). Causes:
- **Synthesis never flushed.** Take the last top-level `**Verdict**` block; group by `subagent_type` for finished lenses. Before writing it: no `INTEGRITY-FAIL.txt`, `pr-diff.reference` sha == footer, no review writes, head unchanged ([unflushed](../learnings/1783983883017-slang-pr-review-reviewer-a-600s-bg-wait-ceiling-tr.md)).
- **Subagents finished, lead did not.** Recover lenses from `task_notification` records (summary >200 chars) matched by `tool_use_id`; `status:"stopped"` w/o output = ceiling hit ([dead lens](../learnings/1789483811315-reviewer-a-final-review-md-can-be-a-truncated-stub.md)). Disclose unfiltered; name the missing lens. `reviewerA.log` holds the text untruncated (C's: `C-<pr>.log`, strip `N\t`); hand-made extracts can cut summaries at 4000 chars — check lengths ([reviewerA.log](../learnings/1791094754719-reviewer-a-subagent-outputs-recover-full-text-from.md)).
- **Trailing heartbeat.** A Monitor heartbeat read as input can stub a finished review to ~200 B. Recover the earlier top-level turn from `**Verdict**` on, recomputing counts (#13244) ([heartbeat](../learnings/1790181801645-reviewer-a-final-review-md-can-be-a-stub-recover-t.md)).

**The merge step can drop a verified crash.** On #11709 R2 a subagent's null-deref SIGSEGV, absent from A's 0-bug review, reproduced: grep summaries for bug/crash/null/SIGSEGV and reproduce hits ([merge](../learnings/1790744483226-reviewer-a-s-merge-step-can-drop-a-subagent-s-veri.md)).

## Concurrent runs on the shared checkout

**Find your run dir** from the runner's echo (A: `>>> final review: <path>`, C: `>>> output → <path>`), never `ls -dt`/`-newermt`. A's `pr-<ts>` lacks the SHA: grep a head-unique token in `pr-diff.reference`. A `bash … ; echo "exit: $?"` wrapper masks exits — read `devin-error.txt` ([echo](../learnings/1790159323514-resolving-a-slang-pr-review-runner-run-dir-under-c.md), [ls -dt](../learnings/1789507730747-slang-pr-review-runner-identify-a-run-dir-from-the.md)).

**False INTEGRITY-FAIL.** With the default `REPO_ROOT` the guard re-reads the shared `tmp/pr-diff.patch`/`tmp/context.json`, which concurrent runs overwrite (recipe: [integrity & concurrency](review-process-f0909b0-reviewer-a-integrity-concurrency.md)). Launch A with `REPO_ROOT=/workspace/agent/wt-<pr>-revA`, a detached head worktree ([isolate](../learnings/1789053876664-slang-pr-review-runner-concurrent-runs-race-on-sha.md)). If it fires anyway: footer `<sha>` == `headRefOid`, footer `diff sha256` == `sha256sum pr-diff.reference`, findings cite the PR's files, `summarize.py` drift==0; never delete another run's tmp files ([four checks](../learnings/1789518412257-concurrent-slang-pr-review-runner-sessions-collide.md)). The CLI often self-heals into `tmp/iso-<pr>-review/pr-diff.patch` while `context.json` stays polluted: use the verified sha as `diff_hash` and disclose the race ([self-heal](../learnings/1789506920553-slang-pr-review-runner-integrity-fail-can-be-a-fal.md); probes on [concurrent reviewer dispatch limits](review-concurrent-reviewer-dispatch-limits.md)).

**Mid-review PR head moves: prestage pins the head.** `prestage.sh` writes `tmp/pr-diff.patch`/`tmp/context.json` once at first dispatch; C reuses them, so a head pushed between the A and C dispatches does NOT split the review targets — verify via `sha256sum` vs the A run's `pr-diff.reference`. Before re-running over a mid-review push, verify the delta: a comment-only delta leaves every finding applicable. Reviewer A may `edit` only its own scratch candidates under `<checkout>/tmp/review-candidates/` — check `tool-uses.jsonl` targets before suspecting contamination ([prestage pins the head](../learnings/1795000278066-mid-review-pr-head-moves-prestage-pins-the-head-ve.md)).

**Post-last-round and test-only pushes are verified directly, not re-reviewed.** A fixer's "disposition pushed" report after the LAST round is not a new review request: #14663 r3's delta implemented the reviewers' own suggested fixes verbatim, so a direct diff verification (fetch head, diff r2-head..r3-head, check each named nit) sufficed, with CI proving the test pins. A fresh dispatch is only for a genuinely new request or a substantive unseen change ([post-last-round disposition pushes](../learnings/1795189246936-post-last-round-disposition-pushes-verify-by-direc.md)). A **test-only** mid-round push folds the same way: line-by-line verification plus running that one test at the new head with the existing binary, naming per-reviewer heads ([test-only mid-round pushes](../learnings/1795243541774-reviewer-spec-misreadings-repeat-inverted-across-r.md)).

**A session error mid-OUTPUT_REVIEW aborts the step, not the review.** On #14669 r1 the codex call died after all three reviewers had exited 0: re-verify the artifacts and unchanged head, retry just the aborted step, and deliver — re-running A/B/C on intact files burns 30+ reviewer-minutes. A codex OUTPUT_REVIEW with no `### Attested` section binds no hashes, so patching an acknowledged typo before delivery is safe ([session error mid-OUTPUT_REVIEW](../learnings/1795204725512-session-error-mid-output-review-resume-surviving-r.md)).

**False REVIEW-GUARD FAIL.** The `looks like an infrastructure error` check trips on infra wording ("transient API errors", an `exit(-1)` finding) and on "rate-limit failures" prose in a COMPLETED review (#14522: 11.3 KB real review): a full Verdict + Findings review is a false trip; a <500 B verdict-less stub is real ([wording](../learnings/1789512038521-slang-pr-review-runner-review-guard-fail-can-false.md)). Adjudicate, don't re-dispatch: `summarize.py` (verdict + drift==0 proves completion), the provenance line vs a live `gh pr diff | sha256sum`, then use the review and note the incident. In a 429 storm detached runs die three ways: (a) inner subagents killed mid-run (0-token agents → partial, re-dispatch); (b) launcher killed (dead pid, NO exit-status → re-dispatch); (c) 429-exhaustion (→ CLARITY-INCOMPLETE → re-dispatch). Setsid runs survive outer-session 429s but not (b) — re-check `pid`+`exit-status` after any interruption ([REVIEW-GUARD false-positive; 429 kill shapes](../learnings/1794897242707-review-guard-false-positive-on-rate-limit-prose-42.md)).

**Reviewer C mis-capture.** `clarity-review.md` <2 KB lacking the `### `/`## Kept`/`## Review Body` headers: the review went to `tmp/` ([tmp/](../learnings/1789573892015-clarity-runner-reviewer-c-can-lose-its-output-to-a.md)) or a trailing meta-message was captured ([meta](../learnings/1789517911038-slang-clarity-review-runner-can-capture-a-trailing.md)). Recover the largest `## Review Body`/`## Kept` text from `stream.jsonl`; scope the drift grep to command fields (a bare `PATCH` matches prompts).

**Refute reviewer "harness behavior" claims against the PR's CI tree, not your worktree's base.** GitHub CI builds the merge of the PR branch with CURRENT master, so a local refutation can pass just because your branch predates the harness-changing master commit (#14248 r2: #14573 added the slang-test exit-code check). Before refuting: merge master, re-run, prefer the corpus's post-change convention. Post-#14573 slangc exit codes are positive (CompilationFailed=2); slang-test's `exit-code` accepts 0/1/2 ([refute against the CI merge tree](../learnings/1794993700461-refute-reviewer-harness-claims-against-the-ci-merg.md)).

## Runner setup, cited files and posting

- **Where and how.** From read-only `/app/skills` the scripts fail `mkdir` in seconds while looking complete — use `/home/node/.claude/skills/<runner>/scripts/` ([writable](../learnings/1789621947264-slang-pr-review-runner-scripts-must-run-from-home-.md)). `gh auth status` 401 is a **false negative under the OneCLI proxy** — probe with one real read first ([gh auth false negative](../learnings/1794908670329-gh-auth-status-false-negative-under-onecli-proxy-p.md); [Devin fetch via detach.sh](../learnings/1794900109239-devin-fetch-via-detach-sh-gh-auth-status-red-herri.md)).
- **slang-rhi PRs.** Keep `REPO_ROOT` on the slang checkout, pass `--repo shader-slang/slang-rhi --pr <N>`; vendored `external/slang-rhi/` may lag the head — verify hunks with `gh pr diff`. ([slang-rhi](../learnings/1789438594576-slang-pr-review-runner-reviews-slang-rhi-prs-with-.md)).
- **Artifacts and cited files.** Copy `final-review.md`, `clarity-review.md`, `tool-uses.jsonl` to `/workspace/agent/review-<pr>/` at once (`transcripts/` is shared). B via agent-browser can't launch Chrome here (dbus): deterministic skip. Drop A's findings on files absent from the PR's file list, keeping any true kernel. ([cited](../learnings/1783681518930-verify-reviewer-a-s-cited-files-against-the-author.md)).
- **Posting.** `post-review.sh` POSTs the body verbatim (event=COMMENT), no bot disclaimer: append it first ([disclaimer](../learnings/1783665412901-post-review-sh-posts-body-verbatim-no-bot-transpar.md)). REST review-body edits 404 under the App token; edit via GraphQL `updatePullRequestReview` (keeps COMMENTED) ([GraphQL](../learnings/1783669185294-slang-pr-review-rest-review-body-edit-404s-under-a.md)).

## Devin infra

**Devin-only tier: retry once.** Exit 3 usually means Devin is still cold-starting: confirm the head, reap Chromium, retry once wider (`--max-minutes 18 --poll-seconds 45`) ([#12107](../learnings/1784074357103-approver-infra-abstain-devin-timeout-on-the-sole-s.md), [reap](../learnings/1783993723797-approver-infra-abstain-devin-only-tier-retry-a-tim.md)). Never retry past a `synchronize` (exits 2 = auth wall, 4 = browser). Checkpoint state to `tmp/STATE.md` early; #13425 still timed out thrice ([#13425](../learnings/1791132067717-reviewer-a-slang-pr-review-runner-runs-out-of-budg.md)). On the primary harvest tier Devin is best-effort, a stall non-blocking: start early, wait ≤~3 min after the primary lands, record `devin: skipped_stall` ([stall](../learnings/1784042688985-approver-infra-abstain-devin-devin-fetch-sh-stall-.md)).

**In `/slang-pr-review`, B runs once** (15-min cap), never retried or gated on `isDraft` — Devin renders drafts for anonymous viewers; the 2026-09-17..10-13 failures were a `devin-fetch.sh` done-check defect (fixed in slang-skills #62) ([B runs once](../learnings/1791964273446-correction-devin-review-renders-for-anonymous-view.md)). Dispatch B through `detach.sh` + `wait-run.sh` — B is wait-run-compatible with A and C (#14526) ([Devin fetch via detach.sh](../learnings/1794900109239-devin-fetch-via-detach-sh-gh-auth-status-red-herri.md)). Re-fetching into the same run dir: `rm` the stale `exit-status` first (checks keep reading the previous fetch's code); fetch once, wait ~9-10 min, `rm`, re-fetch, check `devin-commit-status.txt` equals the reviewed head ([prestage pins the head](../learnings/1795000278066-mid-review-pr-head-moves-prestage-pins-the-head-ve.md)).

**Invocation.** A by-path `devin-fetch.sh` exits 126, faking a skip (lost exec bit): use `bash <script>` ([exec bit](../learnings/1783997801258-approver-devin-fetch-sh-missing-exec-bit-false-ski.md), [#13429](../learnings/1791151479459-slang-pr-review-runner-scripts-may-lose-exec-bit-r.md)). An outer `timeout` under `--max-minutes` yields 124/137, not 0/2/3/4, faking ABSTAIN_INFRA ([no outer timeout](../learnings/1783934997171-approver-infra-abstain-devin-fetch-sh-never-wrap-i.md)); invoke approver scripts via `python3`/`bash` ([invocation](../learnings/1783960724921-approver-ops-invoke-approver-scripts-via-python3-b.md)).

**Silent-data traps.** The extractor mis-parses "N Flags" triplets, writing "(none reported)" while `devin-page.txt` shows flags — reconcile with `rg -n 'Bugs|Flags|Informational'` ([Flags](../learnings/1786488777764-approver-infra-abstain-devin-fetch-extractor-silen.md)). `devin-commit-status.txt` = `"unknown"` after a `synchronize` is a cached prior-revision analysis: verify each finding on the pinned head's `compare` delta ([unknown](../learnings/1784016854486-approver-infra-abstain-devin-commit-status-unknown.md)). A companion clang-format PR on a force-pushed branch makes Devin miss the parent's merge delta: compare Devin's file count with live `base...head`; mismatch is ABSTAIN_INFRA ([companion](../learnings/1784021932868-approver-infra-abstain-companion-clang-format-pr-b.md)).

## Critique-gate hygiene

The gate records a round only for the exact `/codex-critique` format ([format](../learnings/1783939165247-approver-critique-mustfix-critique-gate-only-recor.md)), so DECISION_REVIEW and OUTPUT_REVIEW are separate calls; use `reason_code=CLEAN` for WOULD_APPROVE ([separate calls](../learnings/1783978376082-approver-critique-mustfix-output-review-must-be-it.md)). Per-revision `[Approval Decision]` delivery to the dashboard is mandatory, separate from the `[Report]` ([per-revision](../learnings/1783958368120-approver-critique-mustfix-per-revision-approval-de.md)).

`/app/hooks/gate-critique-on-deliver.sh` matches `gh api [^|]*pulls\b`, so read-only GETs trip it; it denies on `edits_since_critique>0` or a stale OUTPUT_REVIEW; 3 denials hard-block. Diff R2/R1 `review-doc.md` locally, read PRs via `gh pr view --json`/`gh graphql`, never write a file inside a read command ([GET trips](../learnings/1783913716215-approver-critique-mustfix-critique-gate-false-posi.md)).

`reviewers_complete:true` is checked against disk: true only once `devin-flags.md` exists or a bot review was harvested — never pre-fill before Devin is terminal ([pre-fill](../learnings/1784049951184-approver-critique-mustfix-never-set-reviewers-comp.md)).
