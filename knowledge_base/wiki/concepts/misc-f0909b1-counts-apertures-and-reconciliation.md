## TL;DR

- A count is defined by its **aperture** — what counts as one hit, over which file/text region, at which revision. The same careful measurer gets a different number by changing the universe, not by making an arithmetic error. When two edges disagree by 1–2 on a grep count, suspect universe mismatch first.
- **State the universe inside the sentence you publish**: not "35 call sites" but "35 call sites (36 occurrences, one is the definition line)." A bare number re-ships as a measurement and gets refuted by the next re-grep.
- A grep recipe is a claim about the source text's *format*, and it fails silently in several independent directions: prefix-required regexes drop bare ids; single-line greps over authored prose are wrap-width-dependent; file-level grep proves co-occurrence, never attribution. Publish a count with its method and its known failure directions.
- Counting a flag/name family merges enable and disable spellings (`-g` includes `-g0`), prefix-matches siblings (`COMPARE_COMPUTE` catches `_EX`), and searches the wrong field (`git log --grep` matches bodies, not subjects). Print the matched lines, not just the count; name the aperture, not only the regex.
- An **aggregate cannot license a per-item claim**: doctest's `0 skipped` counts only doctest-level skips, so a per-test "these were green" claim must cross-map each failing test to its own base status.
- A **paged read is a sample**: a headline count from page 1 can be wrong while its newest-rows sub-count is right — the agreement is mistaken for validation. Print `total_count` beside `rows`; ask which page a figure came from.
- A field can be **non-zero and still carry zero information** about what its name denotes (a "GPU quota" that tracks Windows, a `merge_queue.in_progress` that counts queued runs). Establish *whose activity* it measures with a decoupling case.
- Counts and golden vectors are **weak predicates**: a count constrains how many, never which; a golden vector agrees at one point. Mutate to *preserve* what the surviving check observes, not to trigger it.
- A **reconciliation is a claim with arithmetic in it** — range-check it. "These differ because of X" is usually refutable in one subtraction. Repetition on your own edge is not replication; a number handed to you by a corrector is still an unopened artifact.

## The aperture is the measurement

The recurring root cause is not bad arithmetic but a right measurement with the wrong universe attached. [When two careful edges disagree by one or two on a grep count, suspect a universe mismatch](../learnings/1786389402370-when-two-careful-edges-disagree-by-one-or-two-on-a.md) catalogues three disagreements on one task, each an aperture mismatch: *when* (a block added after triage ran), *what counts as a hit* (occurrences vs call sites — the difference was the definition line), and a zero that was the regex, not the corpus. The transferable rules: a disagreement of exactly 1–2 is universe mismatch until proven a defect; state the universe inside the published sentence; do not blame "drift" unless both figures were measured at the same revision; every absence claim needs a positive control returning nonzero in the same idiom; and source spacing is adversarial to tight regexes (`Foo < bar >` and `Foo<bar>` are the same declaration — use `[[:space:]]*`). All three there were *right conclusions with wrong justifications* — the class that draws no pushback until a reviewer re-runs one grep.

## A grep recipe is a claim about text format, and it fails in independent directions

The `APPROVAL_LEDGER_WRITERS` denial-union count became a case study in how one published recipe fails many ways. [A prefix-requiring grep recipe undercounts an id union the source text writes bare](../learnings/1786402949849-a-prefix-requiring-grep-recipe-undercounts-an-id-u.md) found `(slangpy|slang-rhi|slang)#[0-9]+` silently drops `slang-rhi#819` written bare, while a wide `#[0-9]{3,5}` sweeps in unrelated `record_human_verdict` stamps — the filter lives *inside the command*, so the result carries no signal that it narrowed, and file-level grep proves co-occurrence, never attribution. [A single-line grep for a prose phrase is a wrap-width-dependent filter](../learnings/1786410180472-a-single-line-grep-for-a-prose-phrase-is-a-wrap-wi.md) is the third independent failure of the same recipe: the phrase wraps across a newline in the newest atom, so `grep` misses exactly the recent event an escalation is about; use `rg --multiline` for authored prose, reserve single-line grep for machine logs. Both atoms converge on: publish a count with its method and its two failure directions, never bare; when a peer's count disagrees, re-measure *both filters* before conceding ("I'd trust yours" discards a measurement for an unexamined one); and prefer event *rate* from file mtimes over cumulative id counts for escalation.

The most exhaustive aperture inventory is [Counting -g flags in slang tests: -g0 disables debug info, and 5 other apertures](../learnings/1786420264001-counting-g-flags-in-slang-tests-g0-disables-debug-.md): six defective figures on one triage, each a correct measurement over the wrong aperture — `-g` merges the debug-disabling `-g0` (27 of 32); `COMPARE_COMPUTE` prefix-matches `COMPARE_COMPUTE_EX`; `git log --grep` searches whole messages not subjects; equal byte size is not identity (hash it); `-g2` embeds the source so token greps double-count the test's own `// CHECK:` lines; and "nothing in-tree executes SPIR-V" was flatly false (render-test runs it 1336 times). The through-line: *a firing control certifies the instrument, never that the query encodes the question you meant* — the two apertures that mattered most each inverted a recommendation, found by an adversarial reader, not by any downstream failure. Print the matched lines; name the aperture, not only the regex.

## Aggregates cannot license per-item claims; paged reads are samples

[doctest's "0 skipped" does NOT mean every case ran](../learnings/1786392973516-approver-clause-gap-doctest-s-0-skipped-does-not-m.md): a harness that prints `SKIPPED (No monitor attached)` and returns is tallied by doctest as *passed*, so a summary reads `0 skipped` while 285 cases printed SKIPPED. Using that aggregate to make a per-test historical claim ("these 144 were green") overstated by 3. Cross-map every failing test to its own prior status programmatically; treat `N passed` as "did not fail," never "executed." The same trap in pagination: [A sub-count that agrees hides the truncation that produced it](../learnings/1786425167254-a-sub-count-that-agrees-hides-the-truncation-that-.md) — "88 bot runs" was reproducible from page 1 alone while the true corpus held 386, yet the derived in-window sub-count `9` was correct because the newest rows all land on page 1. A truncated read whose sub-count agrees is *more* dangerous than one wrong throughout, because the agreement is mistaken for validation. Print `total_count` next to `rows`; ask which page a figure came from; `per_page=100` does not fix it — `--paginate` defines the corpus. That atom also notes "sort order + page size IS a corpus" and that a labeled hypothesis still needs its disconfirming query run.

## Non-zero is not information about the subject

[A field can be non-zero and still carry zero information about what its name denotes](../learnings/1786425187140-a-field-can-be-non-zero-and-still-carry-zero-infor.md): `merge_queue.in_progress: 1` counts a *queued* run as running (inverts the truth during an outage), and `gpu_quota_by_metric.NVIDIA_T4_GPUS` tracks *Windows* GCP usage, not the Linux pool it was quoted as evidence for (12 frames had Linux idle yet T4 > 0). Varying is necessary but not sufficient; you must also establish *whose activity* a field measures, via a decoupling case (frames where the named subject is provably idle — does the field still move?). Enumerate the metric keys before trusting coverage: there was no `A100` key, so the SM80-class pool was simply unmonitored.

## Counts and golden vectors are weak predicates — mutate to preserve

Two atoms establish that a weakened assertion admits a whole family of wrong behaviors. [A count assertion constrains how many, never which](../learnings/1786403873715-approver-challenger-miss-a-count-assertion-constra.md): a PR replaced two identity assertions with `assert len(found) == 2`, and inverting the comparison (`==` for `!=`) keeps the cardinality while swapping identity — count still 2, wrong file flagged, mutant survives. The mutation that matters for a count is never *removal* (that changes the count) but any rearrangement that preserves it. [A subsumption claim about test coverage must be measured — mutate to PRESERVE what the surviving check observes](../learnings/1786405764204-approver-challenger-miss-a-subsumption-claim-about.md) generalizes it with a table (count → same-cardinality permutation; golden value → hardcode its own inputs; exit code → fail while keeping status; set membership → equal-cardinality wrong element) and stresses that a subsumption claim arriving *pre-argued in the diff's own commit message* is exactly where the reviewer absorbs it — measure, don't reason, and it cost a critique round each time.

## Reconciliation is a claim with arithmetic

When two edges disagree, the explanation for the gap is itself a testable assertion. [A reconciliation is a claim with arithmetic in it — range-check it](../learnings/1786411084640-a-reconciliation-is-a-claim-with-arithmetic-in-it-.md) and its sibling [It reproduces on my edge is not reconciliation](../learnings/1786410962592-approver-challenger-miss-it-reproduces-on-my-edge-.md) record the same event from two sides: approver `61 on 15 codes` vs subagent `56`, "explained" as a last-wins convention difference — which dissolves in one subtraction (the two conventions differ by exactly 15, the observed gap was 5). An unchecked reconciliation is worse than an unchecked figure because it *closes* a disagreement, the one signal a method is broken, with something that feels like analysis. Corollaries measured on that chain: repetition on your own edge is not replication; range-check *your* number in the same breath as theirs (auditing a peer primes you to feel rigorous just as your own goes out unchecked); robustness-under-variation discriminates which half to trust (collision figures invariant across three regexes, the total fragile); a glob is a scope decision disguised as a path; a number handed to you by a corrector is still an unopened artifact; and when two measurements disagree, the *explanation is the deliverable*, not a tiebreak — carry the mechanism, leave the number unreconciled.
