## TL;DR

The slang/slangpy PR-approver records WOULD_APPROVE / BLOCK / ABSTAIN_POLICY decisions, then the host auto-joins the terminal GitHub outcome (merge/close) so each decision can be scored against a human verdict. This page is the *calibration ledger*: what shapes reliably merge-as-decided (safe to approve), and how to score joins honestly.

Core scoring rules distilled here:
- **Score an abstain against its falsifiable reading**, not "a human must look; a human looked." A merge at your *exact decided head with zero interval commits* refutes "material enough not to merge as-is."
- **Merged-unchanged is the strongest confirming datum** — it means nothing a clean approval could have masked; verify head==decided-SHA before scoring, and diff the interval (and the PR *body/reviews*, not just code) if the head moved.
- **Self-merge / self-close / no-review merge is neither agreement nor disagreement.** A *non-self* maintainer approve+merge is agreement; an authorized-human decline *with a merit rationale* vindicates an OUT_OF_SCOPE withhold.
- **Two kinds of abstain calibrate differently.** Hard-cap policy abstains (`tier_eligible`, `head_provenance`) are deterministic tripwires — merging unchanged confirms them working, not an over-conservative miss. Judgment-call abstains (`OPEN_GAP`, `CHALLENGER_CONCERN`) are where the "am I over-abstaining?" scrutiny belongs.

**Confirmed safe shapes** (merged-as-decided, WOULD_APPROVE well-calibrated): loosening-only CI-workflow YAML (timeout bump + comments); CI workflow-split/refactor that is a verbatim move; make-a-check-non-required (removal from `check-ci.needs` while the job still runs green); helper-relocation / lexical-scope fix on non-critical tooling with a both-directions guard test; one-line correct-idiom preprocessor-macro fix with a small enumerable consumer set; removing a hard-coded `OpExtension` when a deferred emitter mechanism already covers it; a runtime-demonstrated concurrency/lock-reordering fix that re-enables the regression tests it disabled.

**Recalibration:** an *unproven* accounting-omission on an *untriggered* nested sub-path, by a trusted member, with only the standing zero-exec-coverage hole, is closer to ADVISORY than OPEN_GAP — reserve OPEN_GAP for a reachable trigger on the supported path or a demonstrated wrong result.

## Confirmed-safe shapes (merged as decided)

Several joins upgrade a decision-time note to a full merge-outcome confirmation. A CI-workflow diff that changes **only** `timeout-minutes` (increase) plus comments — no `runs-on`/`permissions`/`on:`/`secrets`/run-steps touch — is empirically safe and ships unchanged; it is the CI analogue of the "widening-only" exemption, owing no positive control [confirmed-at-merge on slang#12684](../learnings/1787752945013-approver-human-agreement-confirmed-at-merge-slang-.md). A pure workflow-split/refactor is safe when the moved job body is a *verbatim* move (the only delta a hoisted `workflow_call` input whose default equals the old literal), the new `needs:` edge matches the artifact the job actually consumes, and a live-gate positive control proves the new check-run actually **ran** (green ≠ ran) [safe-shape checklist for a CI workflow-refactor](../learnings/1787754486474-approver-human-agreement-safe-shape-checklist-for-.md).

The **make-a-check-non-required** shape (removing a job from `check-ci.needs`) routes to WOULD_APPROVE — not ABSTAIN — when the loosening is the declared intent, the removed job still runs and reports, nothing is masked *right now* (the removed check is green on head), the author is trusted, and it is reversible/documented; the dead-flag positive-control probe does not apply because there is no new flag [make-a-check-non-required](../learnings/1787820641277-approver-confirmed-safe-make-a-check-non-required-.md). A **helper-relocation / scope-fix** on non-critical tooling (e.g. `extras/ci/`) is safe when the new declaration dominates *all* call sites (read every call site), no duplicate symbol survives, and a structural source-string assertion serves as the both-directions regression guard where no runtime harness exists [lexical-scope helper-relocation fix](../learnings/1787828402979-approver-human-agreement-lexical-scope-helper-relo.md). A **one-line correct-idiom preprocessor-macro fix** (adding `inline` to `always_inline` for GCC) is well-calibrated when every consumer of the symbol is enumerated and benign, the idiom is known-correct, and both-directions CI on the guarded branch is green [trivial correct-idiom compiler-macro fix](../learnings/1787897757149-approver-human-agreement-trivial-correct-idiom-com.md).

Two deeper compiler/runtime changes also merged as decided. Removing a hard-coded `OpExtension "SPV_KHR_ray_tracing"` from a core-module intrinsic body was safe because a deferred emitter "any-extension" group already covers it — but only after confirming all *three* extension-declaration paths still fire, not just the fixed one [ray-query-only AS-constructor extension leak fix](../learnings/1787888898374-approver-confirmed-safe-ray-query-only-as-construc.md). A profiler collector concurrency fix that consolidated three mutexes into one "causal cut" merged with a human approve; the confirmed-safe signal for an async-collector/lock-reordering fix is a happens-before edge captured under the same mutex that later signals completion, a live setter for every new generation counter, and a consolidation that makes two independent snapshots co-atomic (which tightens, never loosens) [confirmed-safe profiler concurrency fix](../learnings/1787845795403-approver-calibration-confirmed-safe-shape-same-aut.md).

## Scoring joins honestly

The **fragile abstain**: when code is clean on every reviewer axis and the *only* blocker is an author's self-declared "prototype / not for merge" label plus a deferred design question, the abstain carries no code content and can flip to approve-equivalent the instant the author retracts the label — with zero code delta. It is still correct to abstain while the label stands, but log it as a readiness/process abstain and expect the merge; a SHA join alone misses the flip because a body edit moves no head [clean-code abstain grounded only in a not-for-merge label](../learnings/1787758792079-approver-human-disagreement-clean-code-abstain-gro.md).

**Hard-cap abstains are tripwires, not misses.** A 367-commit, ~58k-line automated branch-sync abstained on `CLAUSE_FAIL:tier_eligible`, then a human merged it unchanged at the exact decided head with zero reviews — this is the tripwire *succeeding* (the alternative is auto-approving a 600-file diff), recorded confirmed-correct, not re-tightened from one benign merge [tier_eligible abstain → merged unchanged is correct](../learnings/1787796645997-approver-human-disagreement-tier-eligible-abstain-.md). Likewise the `head_provenance` (fork-head) abstain on slang#12805 merged unchanged: correct-but-non-value-adding for a trusted-member fork, feeding the `allow_fork_head` policy-relaxation case [fork-head abstain #12805 merged unchanged](../learnings/1787865489722-approver-infra-abstain-fork-head-abstain-12805-mer.md).

**OUT_OF_SCOPE spec/proposal joins** score by *who closed and whether a merit rationale was given*. A bare author self-close-unmerged is the mirror of a self-merge — weak, consistent-but-not-refuted [spec#61 author self-close is weak signal](../learnings/1787763317108-approver-human-agreement-spec-61-out-of-scope-join.md) — but when the closer is a maintainer/architect who articulates the exact reserved language-design call (Theresa Foley withdrawing spec#61 for merit reasons), that upgrades to moderate vindication of the OUT_OF_SCOPE *routing* [spec#61 vindication receipt](../learnings/1787763967042-approver-human-agreement-spec-61-vindication-recei.md). A website *build-config* abstain (`docs/conf.py`) held up when a non-self maintainer approved+merged at the exact decided head — the first `:website-build-config` sub-class join, moderate positive evidence the read was right without licensing future approvals on that out-of-domain repo [website build-config out-of-scope vindicated](../learnings/1787790528941-approver-human-agreement-website-build-config-out-.md).

**Confirmed-correct rejections.** A release PR with 4 RED `build (linux, x86_64…)` jobs from a FetchContent 404 was abstained (CHALLENGER_CONCERN) and then closed-unmerged with no human review and a deleted branch — the fingerprint of a mechanical recut, distinct from a merits rejection. The lesson is "verify the release BUILDS on every platform," and a follow-up recut on a fresh branch is an independent decision [confirmed-correct abstain on red dep-download CI](../learnings/1787955549364-approver-human-disagreement-confirmed-correct-abst.md).

## Two false-safe / disagreement joins that recalibrate weight

A slang-rhi Vulkan **new-feature** PR (push-constant buffers) was abstained OPEN_GAP over a refuted bot Major + an unproven layout-accounting omission on an untriggered nested-PC path + the standing zero-exec-coverage hole — then merged unchanged with an *independent admin* approval. That is an over-conservative disagreement: for a self-contained new feature by a trusted member where the residual is an *unproven* omission on an *untriggered* sub-path, treat it as ADVISORY, not OPEN_GAP; the standing zero-exec-coverage fact is a constant that can't by itself distinguish hold-worthy from mergeable [slang-rhi vulkan new-feature: recalibrate that combo below OPEN_GAP](../learnings/1787917157150-approver-human-disagreement-slang-rhi-vulkan-new-f.md). Contrast the *escalated* false-abstain on slang#12687: the merits verdict was WOULD_APPROVE and matched the merge, but the recorded ABSTAIN came from a manufactured pipeline outcome (a critique-gate *scope* disagreement + a human tiebreaker that timed out to ESCALATED). When the only unresolved item is an author-facing nit on code a human already approved at your decided head, resolve to the merits verdict — never spend a tiebreaker that will predictably time out [escalated false-abstain on slang#12687](../learnings/1787756752241-approver-false-safe-join-confirmed-escalated-false.md).
