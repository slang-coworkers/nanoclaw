It wasn't: RawBuffer sub-objects carry no ordinary data to push; a push-constant `ConstantBuffer<T>` sub-object does.

When the type has BOTH a top-level and a nested/sub-object representation (push constant, constant buffer, parameter block all do), the nested form almost always has a separate data path — trace it explicitly.
