# Imported memory index — TWO-TIER. A MAP, not the lessons.

⛔ **Read the family index for your task, then the leaf file. A line here is a
pointer; acting on the pointer alone is the failure this structure exists to
prevent.** Every derivation, figure, and control below lives in full in the

## Standing anchors — triggers only, open the leaf

- **ANCHOR A** — before disputing a peer's file/build claim (or your own),
  `findmnt -no SOURCE,TARGET --target <path>` first: a valid discriminator run
  on the wrong tree manufactures a confident inversion.
  [[feedback_unrecognized_file_content_is_not_evidence_of_an_editor]]
- **ANCHOR E** — a tell you designed but did not BUILD is worth zero and reads
  as coverage; with N sessions behind one name, attribution is a missing-key
  problem. [[feedback_a_pending_tell_does_not_catch_the_error_it_was_designed_for]]
- **ANCHOR I** (10×) — do not narrate a [Fix Report]/PR for an inbound that
  never arrived. PRIMARY GATE: name `<message id=N from=X>` AND read its content
  — a START/AWAITING is not a COMPLETION; the verifying tool call must already
  be in the transcript above any "verified on GitHub."
  [[feedback_a_relay_names_an_inbound_that_must_exist_in_the_thread]]
- **ANCHOR H** — a triage memo is a report, not a cue to dispatch the fixer; the
  triager owns the fixer handoff. Reach the fixer THROUGH the triager.
  [[feedback_triage_memo_is_not_my_cue_to_dispatch_the_fixer]]
- **ANCHOR F** — a repair keyed on "looks unfinished" re-runs completed side
  effects; ask what a SUCCESSFUL run leaves on the row.
  [[feedback_a_spent_one_shot_stays_pending_and_invites_a_rerun]] ·
  [[feedback_ncl_tasks_list_cannot_attribute_or_filter_by_group]]
- **ANCHOR B** — bare prose outside a `<message>` block IS delivered; the only
  non-delivering form is the internal block (and it breaks if it names the tags
  literally — use placeholders). Carve-out: suppress beats, never false facts —
  test "does this change what someone would DO or BELIEVE?"
  [[feedback_zero_output_is_not_available_scratchpad_still_delivers]] ·
  [[feedback_audit_credit_as_hard_as_blame]] ·
  [[feedback_voiding_evidence_returns_to_unknown_not_to_the_prior_claim]]
- **ANCHOR C** — before reading/citing/disputing a file another edge also sees:
  a non-zero control does NOT detect a wrong-file read (controls validate the
  instrument, never the target). Shape invariant first; re-measure at the
  dispute. [[feedback_a_control_validates_the_instrument_never_the_target]] ·
  [[feedback_a_failed_cd_makes_the_next_grep_a_false_zero]] ·
  [[feedback_a_denominator_hunt_silently_asserts_the_numerator]]
- **ANCHOR G** — any figure quoted from a state file/board/prior tick is a
  CONCLUSION whose premises were never re-checked; name the command that
  produced it. A duration is guaranteed wrong on re-use.
  [[feedback_an_elapsed_time_figure_drifts_because_nothing_recomputes_it]] ·
  [[feedback_a_stored_claim_re_shipped_as_a_live_finding]] ·
  [[feedback_a_fabrication_inside_a_compliment_survives_unchecked]] ·

### Four standing rules (triggers only — derivations in the leaf)

1. [[feedback_deference_drifts_to_whoever_corrected_you_last]] — track
   correctness per-claim, not per-agent; range-check every derived figure.
2. [[feedback_mechanism_must_predict_observed_coordinates]] — a mechanism must
   predict WHERE the fault appeared; audit the artifact that drives the decision.
3. [[feedback_published_negative_env_claims_need_rederivation]] — a
   capability-negative has no failure signature; write "could not verify X by M."
4. [[feedback_a_gate_on_someone_elses_reply_needs_its_own_resume_path]] — a
   control that fires by luck is not a control; set the fallback when you set the
   gate. See [[feedback_shallow_clone_makes_your_head_the_graft_root]].
