## Lessons from this chain (all verified here; several already have concept files)

- **Wrong-tree measurement, 5× on one chain** (wrong file · branch · query · tree · tree again). When citing a line against a peer's branch, **state which tree, and assume `master` unless told otherwise**. A **+4-line offset is the most dangerous mismatch** — large enough to land on different code, small enough that the cited line still looks plausible, so it reads as a peer error. A `git clone --shared` made before a merge **serves the parent repo's packed refs and does not update on `git fetch`**; tells: `git show <sha>` prints nothing for a commit that exists, and `git rev-parse origin/master` disagrees with `git ls-remote`.
- **Set enumeration:** three derivations of one 8-member set gave 6, 7, 7 — **two different wrong sets with the same total**. A matching total is NOT corroboration — **reconcile membership, not the count; publish exclusions with reasons** (both wrong 7s were exclusion errors). A membership audit that asks "is X in?" without "*why* is X in?" passes a false uniform-mechanism claim (LLVM). Cf. [[feedback_a_plausible_wikilink_name_is_a_fabricated_citation]].
- **Shared bot identity (`app/nv-slang-bot`):** "your PR", blame, and credit are all **premises to verify**, and the **transcript is the only discriminator** — every GitHub actor field (timeline `base_ref_changed by …[bot]`, commit author email) is *identity, never attribution*. Four mis-bindings happened here from reading a report arriving on an edge as authorship. A **relay is not a claim of authorship**: provenance is the artifact's, not the quoter's. Cf. [[feedback_a_relayed_claim_about_an_artifact_is_a_filesystem_claim]], [[feedback_two_nv_slang_bot_identities_cla_gate]].
- **State-claim decay:** a base-retarget claim decayed in **81 seconds**; a body-line claim decayed *after* an explicit re-check. **When a peer asks you to relay something, check whether it's still undone before relaying** — but the real remedy is that **the party who can ACT should be the party who CHECKS**; every relay hop adds a decay window no diligence at the relay closes. A **resume note is a state claim** and is the worst place for staleness (its audience is a context that has lost the ability to notice). Cf. [[feedback_ci_terminal_is_not_chain_terminal_arm_the_deciding_axis]], [[feedback_a_gate_on_someone_elses_reply_needs_its_own_resume_path]].
- **`|| echo 0` is a machine for converting a tooling error into a plausible datum** — the fallback value is indistinguishable from a healthy quiet channel's real reading, fails toward the expected answer, and is permanent. **Never let a fallback emit a value that is also a legitimate observation**; emit a `PROBE BROKEN` sentinel or fail loudly. A must-fire control caught a guard that could never fire (`gh api --jq` does not accept `--arg`). `user.type` describes the **account, not the authorship** (`jhelferty-nv`'s board-sync bot posts as `type=User`).
- **The through-line:** each defect was a defect in the *remedy* for the previous one — treat a freshly-agreed fix as the next thing to audit, not the resolution. The compiler analysis (`SLANG_E_NOT_AVAILABLE` as the distinct absent-capability code) never moved; **every defect landed in measurement, relay, tooling, or scoping** — the domain work had review structure; the measurements had none, because each looked like a fact rather than a claim. After a restart, **absence of a memory is not evidence of absence of the action** — query the durable system (`ncl tasks list`) before contradicting a peer who cites it.
