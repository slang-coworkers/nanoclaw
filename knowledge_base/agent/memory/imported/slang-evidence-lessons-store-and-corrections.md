# Evidence lessons — store, corrections & audit-grep

> Standing evidence & verification lessons, split verbatim from [[slang-evidence-lessons-index]] on 2026-09-09 to keep the always-loaded index a topic-map. Rows are unabridged; each links its full derivation. Proofs: [[slang-evidence-lessons-derivations]].

- ⭐**Both failure directions are RELEVANCE errors** — ask *does this bear on my conclusion?* of **disqualifying** evidence as rigorously as supporting. **Destroying a conclusion is harder — over-correcting reads as honesty.** [Full rule](feedback_correction_must_sweep_whole_file.md)

- ⭐⭐[NARROWING ≠ TESTING the premise; CHECK YOUR OWN STORE — then confirm the check WORKS](feedback_narrowing_is_not_testing_check_own_store.md) — narrowing inherits the untested premise, launders it as diligence · **recall, not evidence, failure** · ⭐⭐⭐my store was **UNEXECUTABLE** (0 hits) ⇒ run any "always check X" as a stranger; deliverable = the **INDEX ENTRY** · agreement on an untested premise ≠ corroboration. ⛔**evidence travels with it** → [§2](slang-evidence-lessons-derivations.md). ⭐⭐⭐**RUN THE CHAT-ONLY AUDIT BEFORE CLOSING ANY LONG EXCHANGE** — for each claim you asserted in replies, `tr '\n' ' ' < f | tr -s ' ' | grep -ciF -e '<frag>'` across the store; **a claim stated fluently 3× FEELS recorded and often isn't** (2026-08-03: two independent audits, **two unstored claims, both about verification discipline**). ⚠️Ladder any zero before believing it; the output that matters is `CHAT-ONLY` ⇒ **write to the child, then decide what the hook needs.** The procedure itself was chat-only for most of that session — it is now a command in the child

- [A correction appended ≠ applied — ask WHERE ELSE the claim lives](feedback_correction_must_sweep_whole_file.md) + [18-error study](feedback_sweep_rule_case_study_rhi800.md) — sweep classes (**not numbered in the child ⇒ no count claim**, per the marker-vs-item rule), **carry-through the largest** (needs the POSITIVE half); ⭐⭐**a RESUME TRIGGER GOES STALE SILENTLY** — when the resolution path changes, **REWRITE** the trigger (mark `⚠️SUPERSEDED` + `✅CURRENT`), don't append; the row still reads "HELD" while the named event can no longer occur · ⭐⭐**RECENCY OF EDIT beats any keyword probe as a defect predictor** — audit what you just changed, and ask *"is the trigger still reachable?"*, not *"does the row contain 'RESUME'?"*. ⭐**a SPLIT is a content move**; ⭐⭐its mirror is a **FORWARD REFERENCE** (pointer to a child predating the claim ⇒ links all-green, content never there) ⇒ **content-grep the child when you WRITE a pointer; measure the delta on THAT LINE**; ⭐⭐**MISMATCH ⇒ go to GROUND TRUTH, not your newer text**; ⭐⭐**a SELF-EXPIRING note does NOT expire itself**; ⭐**the DETECTOR needs its own verification**. **`/workspace/shared/` is Main-write-only ⇒ stale shared prose is MY repair** — ⚠️not via `learnings/INDEX.md`. [§3–3d = full classes](slang-evidence-lessons-derivations.md)

- ⭐⭐**MODE 7 — a rule REACHABLE TO THE TEAM but INVISIBLE TO THE AGENT (cross-store).** Fired **both directions in one session**: jkwak's `no ../ #include` directive sat in the fixer's store and was **0 hits** in mine; *never-take-state-from-a-summarizer* sat in `/workspace/shared/learnings/` and was absent from the fixer's 199 files ⇒ **that error fired TWICE, not once.** ⭐⭐**"The corpus knows" is not a property any agent can rely on** — and the SHARED store failing is worse, since its existence creates false assurance. ✅**When a peer cites a rule you don't hold, FILE AND INDEX IT IN YOUR OWN STORE — don't merely comply** (compliance ends with the message; the next fresh context has neither), and **don't assume the shared copy protects your peers.** · ⭐**A sweep's detector will eventually match the note DESCRIBING the detector** — my dead-link sweep flagged `](file.md)`, its own inline example. ⛔**CONFIRM, don't "fix"** (creating it = Mode-4-manufactured-by-repair). ✅Keep a **not-a-link class** before reporting any count (`[[nodiscard]]`, `[[noreturn]]`, `[[LOAD]]` — a store documenting bracket syntax has a false-positive FLOOR), and write sweep docs with placeholders that **cannot resolve** (`<file>.md`, `$f`). · ⭐**A COUNT in an index is a claim that ages the moment you append** ("6 ways" vs 7 sections, same pass) ⇒ prefer no count.
