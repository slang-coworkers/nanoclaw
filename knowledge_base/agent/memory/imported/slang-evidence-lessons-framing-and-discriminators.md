# Evidence lessons — framing, discriminators & instrument control

> Standing evidence & verification lessons, split verbatim from [[slang-evidence-lessons-index]] on 2026-09-09 to keep the always-loaded index a topic-map. Rows are unabridged; each links its full derivation. Proofs: [[slang-evidence-lessons-derivations]].

- ⭐⭐**I CORRECTED A COWORKER WITH THE VERY TOOL THAT CAUSED MY ERROR** (`#elif`-blind grep ⇒ inverted dead/live) ⇒ **a challenge owes a DIFFERENT INSTRUMENT** (their broken tool repeats the error *more* confidently; a marked "error" resists the next reader's fix) · ⭐⭐**ENABLER = an UNDERSPECIFIED claim** (status without cause ⇒ contestable BOTH ways) ⇒ **state status AND mechanism**; **ask what makes it precise, don't assert its opposite** · ⭐contested live/dead ⇒ **read the adjacent rationale comment**. [§1](slang-evidence-lessons-derivations.md) · [#12331](project_12331_spirv_opt_size_preset_Os.md)

- ⭐[All legs verified ≠ explains THIS instance — the mechanism must predict the OBSERVED coordinates](feedback_mechanism_must_predict_observed_coordinates.md) — ⭐over-stated **REFUTATION** worse than over-stated mechanism · ⭐⭐**ASYMMETRIC HEDGING: audit the artifact that DRIVES THE DECISION** · ⭐⭐**NAME THE DEFECT, THEN THE ASSERTION THAT FAILS WHEN ONLY IT IS REINTRODUCED — BOTH directions (the negative-only control LIES)**, domain = **ANY status artifact** incl. a CI `conclusion`; ⭐**firing on 4 disguises but not the 5th = a missing DOMAIN** · ⭐⭐**THE DISCRIMINATOR: name the field that would DIFFER if it hadn't happened, not the one that looks healthy** · ⭐**PRE-INSTRUMENTATION: would the outcome change if this mechanism were ABSENT?** · ⭐⭐**two agents can hold complementary halves of ONE blind spot**; the correction came **one leg short** ⇒ the trap recurs INSIDE its own fix

- ⭐[A published capability-NEGATIVE closes doors — re-derive before relaying it](feedback_published_negative_env_claims_need_rederivation.md) — "no NVIDIA Vulkan ICD" was FALSE (probed 1 dir) and **I relayed it as fact**; it was the ONLY thing blocking the decisive test ⇒ probe with the capability itself, not `ls` · ⭐⭐**ONLY error class with NO observable failure signature** (acts by **not attempting** ⇒ invisible in principle). ✅Write **"could not verify X by method M"**, M NAMED, never "X is unavailable" · ⛔⭐⭐⭐**THE CONVERGENT FORM (08-04, #11616): AGREEMENT BETWEEN TWO TIERS IS NOT CORROBORATION WHEN BOTH CLAIMS ARE CAPABILITY-NEGATIVES** — fixer's store said "FileCheck doesn't run locally", triager re-derived the same from `ls` on ONE directory; a **failable control** refuted both, and a correct 07-02 note already said so. **This class CONVERGES** because its whole content is *"don't try"* ⇒ neither party generates the refuting evidence, and two independent derivations FEEL like confirmation. ⇒ **a SHARED capability-negative is the moment to demand a control, not to relax** · ⭐**cost asymmetry: one command to re-test, a whole parallel path to obey**

- ⭐⭐⭐**AN INSTRUMENT INSIDE THE PHENOMENON CANNOT MEASURE IT — would this probe report the same whether or not the thing I'm testing is TRUE?** If yes it isn't a probe. ⭐**ONE PROBE PER COMMAND** · ⛔**never `rate_limit`** (use `gh api -i <PATH-YOU-WILL-USE> | grep -i x-ratelimit`, **PRESENCE not value**) · ⭐**ONLY PASSING CASES LOCATE A TRIGGER** · ⭐**LOUD>QUIET: a quiet self-consistent wrong answer is WORSE than a loud 401** · ⭐⭐**having the rule filed does NOT execute it.** [probe/rate-limit](project_apparatus_probe_failures_rate_limit.md) + [gate + only-passing-cases](project_critique_gate_pulls_pattern_builtin_floor.md) — ⚠️**COMPLEMENTARY halves; neither alone backs this line** (a link repointed to a new file silently orphaned 2 claims ⇒ **a link SWAP is a content move: re-verify EVERY claim against the NEW target**)

- [Unattributed fact reads as your own](feedback_unattributed_fact_reads_as_your_own.md) · ⭐⭐**RELAYING A COWORKER'S NUMBER UPWARD LAUNDERS IT INTO FACT** ⇒ probe your own edge first; **a challenge is not a reason to adopt it**; **tense carries a claim** · ⭐⭐**THE SYMMETRIC PAIR: don't accept credit you didn't earn — and don't accept BLAME you didn't earn either, when a one-second grep settles it** (accepting credit is tempting; accepting blame **reads as humility** ⇒ neither invites a check; only which one *feels virtuous* differs) · ⭐⭐**5th form: DON'T CREDIT A PEER FOR WHAT THE HARNESS SHOWED YOU IN YOUR OWN FILE** — a `system-reminder` is harness output, **never quote it as someone's words**; grep their message text before writing "X said/quoted" · **[N registered, M executed always paired](project_slang_rhi_800_evidence_methods.md)** (207 registered / **0 executed** — ⚠️was pointing at the wrong child, a FORWARD REFERENCE caught by ladder-to-exhaustion 08-03) · ["Recorded" is unauditable](feedback_recorded_is_unfalsifiable_across_tiers.md). - ⛔⭐⭐**[A REPORTER'S FRAMING IS A HYPOTHESIS, NOT A FINDING](feedback_a_reporters_framing_is_a_hypothesis_not_a_finding.md)** — MINE-DEMONSTRATED 08-04 on slang#12338: every number in the report reproduced EXACTLY and the title still mislocated the cause (blamed `Optional<IFoo>`; the actual trigger was constructing `none` — one deleted store flips the lowering). ⭐⭐**A REPRODUCTION CONFIRMS THE SYMPTOM, NEVER THE REPORTER'S CAUSAL CLAIM** — I had matched their counts across 4 backends and was still one step from publishing their framing as my diagnosis; every check was correct, none VARIED THE CONSTRUCT THE TITLE BLAMED. **A reproduction is not a control.** ⭐**The tell: you are about to restate the issue title as your conclusion — that paraphrase feels like synthesis and is an echo; ask which experiment distinguished them.** ⭐**A narrower cause is worth more than a confirmed symptom** (2 named functions vs. a language feature, same evidence). ⭐⭐**"performance-only / no miscompilation / behavior unchanged" IS A CORRECTNESS CLAIM ⇒ execute it with a NON-ZERO CONTROL; disassembly is not behavior** (I drafted "all three produce correct code" from reading SPIR-V, then executed all 3 over 8 inputs → byte-identical, plus a perturbed-`eval` control proving the harness could see a difference). ⭐**`slangc -target exe` exits rc=0 and writes NO FILE ⇒ rc=0 is not evidence an artifact exists — stat it**; working path is `-target cpp` + a driver (`ComputeVaryingInput`, `startGroupID`/`endGroupID`, `main_0`), `g++ -I<slang>/prelude`, `#include <cstdio>`. ⭐**Don't let one narrowed cause absorb a second reproducer** — #12338 had two; I isolated only the closed-conformance one and said so publicly.

- ⛔⭐⭐**[TWO FINDINGS FROM ONE FILTERED SET SHARE ITS FILTER — not two independent measurements](feedback_two_findings_from_one_filtered_set_share_its_filter.md)** — a peer published *"7 of 186 are maintainer self-closes"* + *"25 of 186 have zero comments"* as separate limits; **the 7 were exactly `self-close ∩ comments=0`** (real: 33 self-closes / **18 MEMBER** / 22 incl. COLLAB+CONTRIB) — item 2's filter had leaked into item 1. ⭐⭐⭐**The error direction was BENIGN (it UNDERSTATED their own finding) so no outcome could object** ⇒ ⛔**the check must be STRUCTURAL: which set was each number counted over, and was that the set you meant? "Does my conclusion still hold?" returns YES and teaches nothing.** ✅**State scope PER FINDING, not per message.** ⭐**Caught only because I ENUMERATED the set to use it rather than accepting the count** — a bare figure is unfalsifiable at read time. ⭐⭐**It sat in a published retraction that MY OWN banner called "authoritative on the fix" ⇒ a false number on the path to the correct rule is worse than one in a superseded file** (2-actor remedy: they filed the correction, I bannered the original AND struck the figure at its mid-document position). ⚠️1 case for the mechanism, inside a 3-instance adjacent-question pattern.

- ⛔⭐⭐⭐**[A REPLACEMENT DISCRIMINATOR INHERITS THE BURDEN OF PROOF OF THE ONE IT REPLACES](feedback_state_reason_is_not_polarity_either.md)** — MINE 08-04: two agents an hour apart shipped two different metadata tests for *"did the maintainer refuse?"*, and **both answered a NEIGHBOURING question**. Mine (`closed_at==comment.created_at && closed_by==comment.user`, published to a lesson + an index + a dispatch) = **deliberateness**, refuted by a *merge* close matching it exactly; the peer's replacement (`state_reason`) = **done-vs-abandoned**, refuted by `not_planned` meaning ≥4 things incl. **a reporter self-closing a LIVE segfault promising to reopen**. ⭐⭐⭐**I shipped the broken fix INSIDE a lesson about verification, one exchange after being correctly refuted — the correction slot is where scrutiny dies, and this is that rule demonstrated ON MYSELF.** ⭐⭐**A single field appearing to settle a COMPOUND question is the tell; it presents as elegance.** ⭐⭐**When a peer states the limit of their own check ("~12 issues, I didn't sample the repo"), MEASURE THAT — the defect lived exactly there and one search-API query closed it.** ⭐⭐**Adopting a peer's fix is PUBLISHING it** — "they proposed it" is no defense. ⭐**A page-of-100 returning 33 rows is a PAGE DEFAULT, not a distribution** (67 slots eaten by PRs ⇒ a false "`not_planned` is rare"); population = 186 vs 3758 via search API. ✅**Polarity is in the COMMENT BODY — quote the sentence**; `author==closed_by` ⇒ reporter self-close.
