Two cases compile on master (`6815ed82d`) but fail with this PR (head `d79256b0f`). In both, `isInlinableAtGlobalScope` refuses a callee because an instruction in its body returns true from `mightHaveSideEffects()`. The call then stays in a module-scope initializer. The enclosing array is a legal global constant, so `inlineGlobalConstantsForLegalization` does not move the call into a function.

**1. Integer division in the helper (no `-g` needed).** Integer `/` and `%` with a non-literal divisor report side effects (`slang-ir.cpp`, `mightHaveSideEffects`).

```slang
[__readNone] [ForceInline] int ceilDiv(int a, int b) { return (a + b - 1) / b; }
static const int arr[2] = { ceilDiv(10, 4), ceilDiv(7, 2) };
RWStructuredBuffer<int> o;
[shader("compute")][numthreads(1,1,1)] void computeMain(uint3 t: SV_DispatchThreadID) { o[0] = arr[t.x & 1]; }
```

- Master emits `arr_0 = { { int(3), int(4) } }`.
- This PR emits `arr_0 = { { ceilDiv_0(int(10), int(4)), ceilDiv_0(int(7), int(2)) } }`.
- `-target ptx`: NVRTC error "dynamic initialization is not supported for a __device__ variable".
- `-target spirv -emit-spirv-via-glsl`: glslang error "global const initializers must be constant".
- `-target shader-sharedlib`: the C++ compiler fails too.

**2. Any pure helper with `-g`.** Debug instructions in the callee body also report side effects.

```slang
[__readNone] [ForceInline] float twice(float x) { return x * 2.0f; }
static const float arr[2] = { twice(1.0f), twice(2.0f) };
RWStructuredBuffer<float> o;
[shader("compute")][numthreads(1,1,1)] void computeMain(uint3 t: SV_DispatchThreadID) { o[0] = arr[t.x & 1]; }
```

Without `-g` this compiles. With `-g`, `-target ptx`, `-emit-spirv-via-glsl` and `shader-sharedlib` fail with the same errors as case 1. Master compiles it with `-g`.

A possible adjustment: in the `default:` case, skip debug-info instructions, and refuse only an instruction that might have side effects and has no uses (a statement). Keep `var`, `load` and `store` refused. In a local build with this change, both cases above and the test in this PR pass.
