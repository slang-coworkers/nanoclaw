### Asking the operator — DECISION NEEDED, or it was never asked

An operator decision exists only once you have posted it to the operator console (slack-surface.md)
and mirrored the identical text on `hermes-<ROW>`, in this shape and no other:

```
DECISION NEEDED — <ROW> — <the question, one line>
1. <option> — <cost / consequence>
2. <option> — <cost / consequence>  ← recommended
default if unanswered by <ISO UTC = this DM + 2 h>: option N (rule C.x)
```

Two or three options, the recommendation marked; the default is one of C.1–C.3 (delegated-decisions.md
§ Standing defaults) or `default: none — waits; not delegable`. The `1.`/`2.` lines are literal — the one
place slack-surface.md's no-`1.`-lists rule yields; the operator answers with the number. In the SAME
turn, stamp the row's ledger `notes`: `decision-needed:<C.x|none> <ROW> <ISO of the DM> — <question>` —
the 2 h clock and "pending operator decisions" read that stamp, never your memory of a DM. "I will
escalate", "your call" or "holding for the operator's go" anywhere without that DM in the same turn is
a violation the supervisor flags as `promised-escalation-missing`.
