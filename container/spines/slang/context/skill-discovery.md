### Additional Slang skills

More specialized skills are available from [shader-slang/slang-skills](https://github.com/shader-slang/slang-skills) (requires `gh` CLI ≥ 2.90):

- Browse: `gh skill search slang --owner shader-slang`
- Preview: `gh skill preview shader-slang/slang-skills <skill-name>`
- Install: `gh skill install shader-slang/slang-skills <skill-name>`

Installed skills become available immediately as `/skill-name` and persist across sessions.
