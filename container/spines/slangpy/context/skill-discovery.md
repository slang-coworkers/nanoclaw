## Additional Skills

Your pre-installed skills cover core workflows. Additional skills are available from the [shader-slang/slang-skills](https://github.com/shader-slang/slang-skills) registry. Requires `gh` CLI >= 2.90.

**Browse available skills:**

```bash
gh skill search slang --owner shader-slang
```

**Preview a skill before installing:**

```bash
gh skill preview shader-slang/slang-skills <skill-name>
```

**Install a skill into your workspace:**

```bash
gh skill install shader-slang/slang-skills <skill-name>
```

Skills install into your workspace and are available immediately via `/skill-name`. They persist across sessions in this workspace.
